# Angular Contact Form

## Aim
To develop a Contact Form using Angular 16 Reactive Forms with built-in form validation.

## Technologies Used
- Angular 16
- TypeScript
- HTML
- CSS

## Description
The application collects user details such as Name, Email, Subject and Message and validates the inputs using Angular Reactive Forms.

## Features
- Form creation using FormGroup and FormControl
- Required field validation
- Email validation
- Minimum length validation
- Validation error messages
- Form submission

## How to Run
```bash
npm install
npx ng serve
